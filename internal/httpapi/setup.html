YardMaster uses HTTPS

This page is served over plain HTTP only to help you move to HTTPS.

{{if .Active}}

1. Trust YardMaster's certificate

{{if .BuiltinCA}}

YardMaster signs its own certificate. Install its certificate authority once on each computer:

Download yardmaster-ca.crt

Check that its SHA-256 fingerprint matches the one in the container log:

{{.Fingerprint}}

Windows: double-click the file → Install Certificate → Local Machine → "Trusted Root Certification Authorities".
macOS: double-click → Keychain Access → System → open the certificate → Trust → "Always Trust".
Linux (Debian/Ubuntu): sudo cp yardmaster-ca.crt /usr/local/share/ca-certificates/ && sudo update-ca-certificates
Linux (Fedora/RHEL): sudo cp yardmaster-ca.crt /etc/pki/ca-trust/source/anchors/ && sudo update-ca-trust
Firefox keeps its own list: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import.

Many coding tools don't read the system list. Point them at the file:

export SSL_CERT_FILE=/path/to/yardmaster-ca.crt        # Python (httpx), OpenAI and Anthropic Python SDKs
export REQUESTS_CA_BUNDLE=/path/to/yardmaster-ca.crt   # Python (requests)
export NODE_EXTRA_CA_CERTS=/path/to/yardmaster-ca.crt  # Node.js tools, Claude Code
{{else}}
